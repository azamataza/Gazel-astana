# Генератор блога Gruzim.kz

Папка начинается с `_`, поэтому GitHub Pages (Jekyll) её не публикует.

- `articles.py` — все статьи блога: факты, текст, вопросы и ответы, ссылки на услуги. Новая статья — новый `dict` в списке `ARTICLES`.
- `build.py` — собирает из `articles.py` страницы `blog/<рубрика>/<slug>.html`, `blog.html`, блок «Наши работы на видео» на главной (3 свежих кейса), записи в `sitemap.xml` и раздел «Блог» в `llms.txt`. Пункт «Блог» в меню добавляет на страницы, где его ещё нет.

Запуск из корня сайта:

```
python3 -I _blog-tools/build.py .
```

Повторный запуск без изменений в `articles.py` ничего не меняет.

Правила для статей:
- Только факты владельца и то, что видно на видео.
- Цены не писать, если владелец их не дал.
- Запросы брать из Search Console; основные ссылки вести на страницы услуг.

Важно (13.11.2026): страницы статей в `blog/` после последней сборки правились напрямую в HTML (блок автора, даты обновления, короткие ответы, таблицы, FAQ по 5 вопросов). `articles.py` эти правки не содержит — перед запуском `build.py` их нужно перенести в `articles.py`, иначе сборка их перезапишет. `llms-full.txt` и `karaganda/llms-full.txt` собираются из готового HTML отдельно.
